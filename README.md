## Task 1: Read a File and Handle Errors

### Features

* Opens and reads a file named `sample.txt`
* Displays content line by line with numbering
* Handles errors if the file does not exist

### Concepts Used

* File Reading (`r` mode)
* Exception Handling (`try-except`)
* Loops
* String formatting

## Task 2: Write and Append Data to a File

### Features

* Takes user input and writes it to `output.txt`
* Appends additional data to the same file
* Reads and displays final file content

### Concepts Used

* File Writing (`w` mode)
* File Appending (`a` mode)
* File Reading (`r` mode)
* User Input
* Context Manager (`with open`)
